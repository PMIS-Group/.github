# PMIS Engineering

PMIS Engineering designs, develops, operates, and maintains software products and technology platforms for the company and its clients.

## Engineering Principles

- Company ownership of source code and technical systems
- Secure and controlled software delivery
- Standardized tools and development practices
- Documented architecture and operational knowledge
- Automated testing and deployment
- Continuous improvement

## Technology Direction

Our primary engineering technologies include:

- PHP and Laravel
- TypeScript, React, and Next.js
- PostgreSQL
- Docker
- GitHub Actions

## Security

Security concerns involving PMIS repositories should be reported through the approved internal security process. Do not disclose credentials or confidential client information in public issues.
